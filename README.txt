JUEGO WEB: "QUIERO QUE ESTEMOS BIEN"
=====================================

Esta versión NO tiene perder, vidas ni plataformas.
Es una experiencia corta y sincera pensada para reconciliarse después de una pelea.

Incluye:
- Subida de dos fotos desde el navegador.
- Las fotos quedan guardadas localmente en ese dispositivo.
- Cinco mensajes interactivos.
- Una pregunta final sin presión.
- Mensaje de cierre que cambia según la respuesta.
- Diseño adaptado a celular y computadora.
- No necesita servidor, Node.js ni base de datos.

ARCHIVOS
--------
index.html
style.css
app.js

PARA PROBAR
-----------
Abre index.html en Chrome, Edge o Firefox.

PARA GITHUB PAGES
-----------------
1. Sube index.html, style.css y app.js a la raíz del repositorio.
2. Ve a Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: / (root).
6. Guarda.

IMPORTANTE SOBRE LAS FOTOS
--------------------------
Las fotos que selecciones desde la página se almacenan solamente en localStorage
del navegador donde las cargaste. Si mandas el enlace a otra persona, esa persona
no verá automáticamente esas fotos.

Si quieres que las fotos ya aparezcan para todos desde GitHub Pages, coloca
las imágenes dentro del proyecto y modifica index.html para usar esas imágenes.
