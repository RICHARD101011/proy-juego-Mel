JUEGO DE RECONCILIACIÓN
========================

Contenido:
- index.html
- style.css
- game.js

Cómo abrirlo:
1. Descomprime la carpeta.
2. Abre index.html en Chrome, Edge o Firefox.
3. En la pantalla inicial toca "Tu foto" y "Su foto" para elegir imágenes.
4. Las fotos quedan guardadas SOLO en ese navegador mediante localStorage.

Controles:
- PC: A/D o flechas izquierda/derecha.
- Saltar: W, flecha arriba o barra espaciadora.
- Celular: usa los tres botones táctiles de la parte inferior.

Cómo publicarlo gratis en GitHub Pages:
1. Crea un repositorio en GitHub.
2. Sube index.html, style.css y game.js en la raíz del repositorio.
3. En GitHub ve a Settings > Pages.
4. En "Build and deployment" selecciona "Deploy from a branch".
5. Selecciona la rama main y la carpeta /root.
6. Guarda. GitHub te dará una dirección web que podrás abrir desde el celular.

Personalización rápida:
- Título y textos: index.html
- Colores y tamaños: style.css
- Mensaje final y niveles: game.js

Nota:
No requiere servidor, Node.js ni base de datos. Es un sitio estático.
